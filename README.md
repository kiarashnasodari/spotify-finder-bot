# ربات پیدا کردن آهنگ اسپاتیفای در کانال‌های تلگرام

لینک اسپاتیفای → اسم و خواننده → جستجو در کانال‌ها → لیست کانال‌ها با لینک پست، حجم، کیفیت (kbps) و درصد تطابق → با دکمه‌ی ⬇️ فایل همون‌جا برات فرستاده می‌شه.

## راه‌اندازی

1. **API_ID و API_HASH**: برو my.telegram.org → API development tools → یه اپ بساز.
2. **توکن ربات**: از @BotFather یه ربات بساز.
3. **نصب**:
   ```
   pip install -r requirements.txt
   cp .env.example .env
   ```
   API_ID، API_HASH و BOT_TOKEN رو تو `.env` بذار.
4. **اکانت جستجوگر**: `python login.py` → شماره و کد رو بزن → خروجی رو تو `SESSION_STRING` بذار.
   ⚠️ بهتره یه **اکانت دوم** باشه، نه اکانت اصلیت.
5. **منابع جستجو** (مهم‌ترین قدم):
   - با اکانت جستجوگر تو کانال‌های موزیک **عضو شو** → جستجوی سراسری همه‌شون رو می‌گرده.
   - کانال‌های عمومی که نمی‌خوای عضو شی رو تو `CHANNELS` بنویس.
6. **اجرا**: `python bot.py` → به ربات `/start` بده → آیدی عددیت رو تو `ALLOWED_USERS` بذار و ربات رو ری‌استارت کن.

## نکات
- **سرور**: تلگرام و اسپاتیفای از ایران فیلترن. یا روی VPS خارج اجرا کن، یا `PROXY` رو پر کن.
- اگه اسپاتیفای اطلاعات رو نداد، دستی بفرست: `Artist - Song`
- آهنگ‌های فارسی که تو اسپاتیفای فینگلیش ثبت شدن و تو کانال‌ها فارسی، ممکنه پیدا نشن → دستی با اسم فارسی بفرست.
- نتیجه‌ی کم؟ `MIN_SCORE` رو کم کن (مثلاً 0.5). نتیجه‌ی بی‌ربط؟ زیادش کن.
- با `nohup python bot.py &` یا systemd/pm2 روی سرور همیشه روشن نگهش دار.
